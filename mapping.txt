================================================================================
  MAPPING DO PROJETO — TypeScriptLab (RPG Reviewer)
================================================================================

================================================================================
  ARQUIVO: src/index.ts
================================================================================

  Carrega dotenv no topo (import 'dotenv/config').
  Configura o SDK do Cloudinary com as variaveis de ambiente.
  Importa e monta os 3 roteadores:
    - /public   → publicRouter   (renderiza a view)
    - /api      → apiRouter      (endpoints de reviews)
    - /api/auth → authRouter     (endpoints de autenticacao)

  Configura:
    - view engine = EJS
    - diretorio de views = ./src/views
    - static = ./src/public
    - parser JSON para requisicoes POST

  Redireciona / → /public

================================================================================
  ARQUIVO: src/types.ts
================================================================================

  Interfaces exportadas:
  ┌─────────────────────────────────────────────────────────────────────┐
  │ RPG { name, owner, genre, image, banner, description, year }        │
  │   → Representa um sistema de RPG (ex: Dungeons & Dragons)           │
  │     banner: imagem grande p/ hero do catalogo Netflix                │
  │     description: texto de apresentacao do sistema                    │
  │     year: ano de publicacao                                          │
  ├─────────────────────────────────────────────────────────────────────┤
  │ Review { id, rpg: RPG, username, rating, comment, timeAgo }         │
  │   → Uma avaliacao publicada por um usuario                          │
  ├─────────────────────────────────────────────────────────────────────┤
  │ ReviewInput { rpgName, rating, comment }                            │
  │   → Dados enviados no corpo do POST /api/reviews                    │
  │   (sem username, pois o username vem do token de autenticacao)      │
  ├─────────────────────────────────────────────────────────────────────┤
  │ User { id, username, passwordHash }                                 │
  │   → Usuario registrado no sistema                                   │
  └─────────────────────────────────────────────────────────────────────┘

  ARQUIVO: src/data.ts
================================================================================

  Camada de dados em memoria (tudo some quando o servidor reinicia).

  ┌─────────────────────────────────────────────────────────────────────┐
  │ DADOS                                                               │
  ├─────────────────────────────────────────────────────────────────────┤
  │ rpgs: RPG[] (exportado)                                             │
  │   8 RPGs com nome, editora, genero, imagem, banner, descricao, ano  │
  ├─────────────────────────────────────────────────────────────────────┤
  │ reviews: Review[] (privado)                                         │
  │   2 avaliacoes iniciais (Cyberpunk Red e D&D)                       │
  ├─────────────────────────────────────────────────────────────────────┤
  │ users: User[] (privado)                                             │
  │   Usuarios registrados (inicia vazio)                               │
  ├─────────────────────────────────────────────────────────────────────┤
  │ sessions: Map<token, userId> (privado)                              │
  │   Mapa de tokens ativos para usuarios                               │
  └─────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────┐
  │ FUNCOES EXPORTADAS                                                  │
  ├─────────────────────────────────────────────────────────────────────┤
  │ getReviews() → Review[]                                             │
  │   Retorna copia do array de reviews                                 │
  ├─────────────────────────────────────────────────────────────────────┤
  │ addReview(input: ReviewInput, username: string) → Review            │
  │   Cria nova review, insere no inicio do array, retorna ela          │
  ├─────────────────────────────────────────────────────────────────────┤
  │ getRpgByName(name: string) → RPG | undefined                        │
  │   Busca RPG pelo nome                                               │
  ├─────────────────────────────────────────────────────────────────────┤
  │ registerUser(username, password) → { user, token } | { error }      │
  │   Valida se usuario ja existe, hasheia senha, gera token, salva     │
  ├─────────────────────────────────────────────────────────────────────┤
  │ loginUser(username, password) → { user, token } | { error }         │
  │   Verifica se usuario existe e senha corresponde, gera novo token   │
  ├─────────────────────────────────────────────────────────────────────┤
  │ getUserByToken(token) → User | undefined                            │
  │   Busca usuario ativo pelo token de sessao                          │
  ├─────────────────────────────────────────────────────────────────────┤
  │ logoutUser(token): void                                             │
  │   Remove o token do mapa de sessoes                                 │
  └─────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────┐
  │ FUNCOES INTERNAS (PRIVADAS)                                         │
  ├─────────────────────────────────────────────────────────────────────┤
  │ hashPassword(password) → string                                     │
  │   Gera salt aleatorio (16 bytes) + hash scryptSync (64 bytes)       │
  │   Retorna no formato "salt:hash"                                    │
  ├─────────────────────────────────────────────────────────────────────┤
  │ verifyPassword(password, stored) → boolean                          │
  │   Extrai salt do formato "salt:hash", recalcula hash, compara       │
  └─────────────────────────────────────────────────────────────────────┘

================================================================================
  ARQUIVO: src/routes/api.ts
================================================================================

  ┌─────────────────────────────────────────────────────────────────────┐
  │ GET /api/reviews?rpg=Nome                                           │
  │   Retorna JSON com todas as reviews. Se ?rpg= for passado, filtra   │
  │   por nome do RPG.                                                  │
  │   Resposta: Review[]                                                │
  ├─────────────────────────────────────────────────────────────────────┤
  │ POST /api/reviews                                                   │
  │   Cria nova review. Requer Header: Authorization: Bearer <token>    │
  │   Formato: multipart/form-data (FormData)                            │
  │   Campos: rpgName (text), rating (text), comment (text),            │
  │           image (file, opcional - jpg/png/webp/gif, max 5MB)        │
  │   - Usa multer.memoryStorage() (buffer em RAM)                     │
  │   - Valida token → extrai username                                  │
  │   - Valida campos obrigatorios                                      │
  │   - Valida se RPG existe                                            │
  │   - Se image enviada → uploadToCloudinary()                         │
  │       → stream do buffer para cloudinary.uploader.upload_stream()  │
  │       → pasta "rpg-reviewer", retorna secure_url                    │
  │   - Chama addReview() passando customImage (URL do Cloudinary)      │
  │   Resposta 201: Review criada (customImage ou rpg.image)            │
  │   Resposta 401: token ausente ou invalido                           │
  └─────────────────────────────────────────────────────────────────────┘

================================================================================
  ARQUIVO: src/routes/auth.ts
================================================================================

  ┌─────────────────────────────────────────────────────────────────────┐
  │ POST /api/auth/register                                             │
  │   Corpo: { username, password }                                     │
  │   - Valida username (min 3 chars) e password (min 4 chars)          │
  │   - Chama registerUser()                                            │
  │   Resposta 201: { user: { id, username }, token }                   │
  │   Resposta 400: erro (usuario existe, campos invalidos)             │
  ├─────────────────────────────────────────────────────────────────────┤
  │ POST /api/auth/login                                                │
  │   Corpo: { username, password }                                     │
  │   - Chama loginUser()                                               │
  │   Resposta 200: { user: { id, username }, token }                   │
  │   Resposta 401: erro (nao encontrado ou senha incorreta)            │
  ├─────────────────────────────────────────────────────────────────────┤
  │ POST /api/auth/logout                                               │
  │   Header: Authorization: Bearer <token>                             │
  │   - Chama logoutUser() → remove token do mapa                       │
  │   Resposta 200: { message }                                         │
  ├─────────────────────────────────────────────────────────────────────┤
  │ GET /api/auth/me                                                    │
  │   Header: Authorization: Bearer <token>                             │
  │   - Verifica se token e valido                                      │
  │   Resposta 200: { user: { id, username } }                          │
  │   Resposta 401: token invalido                                      │
  └─────────────────────────────────────────────────────────────────────┘

================================================================================
  FLUXO DA APLICACAO
================================================================================

  1. Usuario acessa http://localhost:3000
  2. Servidor redireciona / → /public
  3. Rota /public renderiza public.ejs com rpgs[] e reviews[]
  4. Pagina carrega, JS executa verificarSessao() (valida token)
  5. Usuario navega:
     - Stories: clica em RPG → filtrarRPG() (filtro local)
     - Busca: digita → buscarNoFeed() (filtro por texto)
     - Avaliar (sem login) → modal login
     - Avaliar (logado) → modal com estrelas + upload de capa + form
       → imagem enviada ao Cloudinary via memoryStorage + upload_stream
       → secure_url salva como customImage na review
     - Catalogo (substitui Ranking) → overlay Netflix-style:
       banner hero com descricao, grid de todos os RPGs, click muda o hero
     - Entrar → modal login → cadastro se necessario
     - Perfil (logado) → confirm → logout
   6. Tema Netflix (vermelho #e50914) configurável via painel no desktop:
      - Botao "Tema" fixo na lateral direita (só aparece em telas > 1024px)
      - Color pickers para bg, cards, destaque, texto, estrelas
      - Tema salvo no localStorage
      - Botao "Exportar" copia as cores em texto (formato --var: valor)
